## Flagship

| | |
|---|---|
| **[FalconDB](https://github.com/FalconTechDev/falcondb)** `Rust` | A columnar analytical database engine written from scratch: storage, encodings, planner, executor, indices, WAL and SQL front end. Benchmarked against DuckDB, DataFusion and Polars; the method and numbers are in the repository. |
| **[netwatch](https://github.com/FalconTechDev/netwatch)** `Rust` | See which program is using your connection, live. Reads the kernel's own accounting (ETW on Windows, eBPF on Linux) instead of sampling. |
| **[synchronize](https://github.com/FalconTechDev/synchronize)** `Go` | Keep every git repository in step across every machine you work on: sync at login, on a timer, and before shutdown. Windows, Linux and macOS builds in [Releases](https://github.com/FalconTechDev/synchronize/releases). |
| **[falconnet](https://github.com/FalconTechDev/falconnet)** `Rust` | SQL, diagnostics and per-process attribution over packet captures: Wireshark that answers questions. |

## Developer tools

Small tools that each answer one question, with measured results rather than claims.

| | |
|---|---|
| **[sql-traps](https://github.com/FalconTechDev/sql-traps)** | The same SQL run on MySQL, MariaDB, PostgreSQL and SQL Server in Docker; the results that differ, with versions and dates. |
| **[workflow-doctor](https://github.com/FalconTechDev/workflow-doctor)** | Where a GitHub Actions workflow loses minutes: per step, retries, cache, critical path, cost. |
| **[flakemap-contrib](https://github.com/FalconTechDev/flakemap-contrib)** | A stability gate for pytest: rerun new and changed tests N times and fail on mixed results. |
| **[jest-polluter-finder](https://github.com/FalconTechDev/jest-polluter-finder)** | Find the minimal set of Jest test files that make a victim test fail (delta debugging). |
| **[dockerfile-diff-size](https://github.com/FalconTechDev/dockerfile-diff-size)** | Which Dockerfile instruction made the image bigger, layer by layer. |
